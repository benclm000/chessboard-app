# Chessboard App

A simple React + TypeScript demo that renders an 8×8 chessboard with algebraic coordinates.  
Clicking on any square logs its coordinate to the console and highlights the selected square.

## How To Run

```bash
# 1. Clone the repo
git clone https://github.com/benclm000/chessboard-app.git
cd chessboard-app

# 2. Install dependencies
npm install

# 3. Run in development mode
npm run dev
